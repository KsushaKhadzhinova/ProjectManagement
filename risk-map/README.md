# Инструмент: Карта рисков в Excel

Заполненная копия оригинального шаблона `to do/Карта рисков в Excel_с форматированием -26 (3).xlsx` с реестром реальных рисков проекта NotaCode и VBA-макросом автозаполнения.

- **`risk-map.xlsx`** — рабочая копия инструмента.
- **`modRiskMap.bas`** — VBA-макрос: заполняет реестр рисков (15 строк) и подписывает точки на карте рисков названиями рисков.
- **`risk_map.png`** — диаграмма карты рисков (вероятность × воздействие), сгенерированная `pz4/calc_and_charts.py`.

## Как использовать

1. Открой `risk-map.xlsx`.
2. Alt+F11 → Insert → Module → вставь `modRiskMap.bas`.
3. Alt+F8 → `RunAll` → «Выполнить».

Подробное описание содержимого инструмента — см. [`to do/Инструмент — Карта рисков в Excel.md`](../to%20do/Инструмент%20—%20Карта%20рисков%20в%20Excel.md).

Этот инструмент используется как вспомогательный материал к заданию **ПЗ1** (см. [`../pz1/`](../pz1/)) — риск-анализ логически относится к бизнес-обоснованию проекта.
