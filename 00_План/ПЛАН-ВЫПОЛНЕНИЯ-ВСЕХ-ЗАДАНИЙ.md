## 2. Общие шаги для каждого ПЗ
1. Переключиться на ветку: `git checkout pz1-concept` (или `pz2-wbs-gantt`, `pz3-risks`).
2. Прочитать в папке лабы `README.md` → `03_конспекты-md/` → `ПЛАН.md`.
3. Выполнить по `ИНСТРУКЦИЯ.md` (автоматически: макрос или Python; либо вручную).
4. Сверить с `ОТЧЁТ.md` — там готовый выполненный вариант.
5. Пройти `ЧЕКЛИСТ.md` (пункты «вручную перед сдачей»).
6. Загрузить .docx и .xlsx на LMS (`courses.bsuir.by`).
