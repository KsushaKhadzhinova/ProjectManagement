# Инструмент: Планировщик проекта на основе диаграммы Ганта

*Источник: `Планировщик проекта на основе диаграммы Ганта - 60121 (3).xlsx`*

Готовый Excel-инструмент с автоматическим расчётом сетевого графика (ES/EF/LS/LF/резерв) и построением диаграммы Ганта по введённым данным. Состоит из четырёх листов.

## Лист «Пример 1» — учебный кейс WBS + длительности

Проект **«Обучение сотрудников кибербезопасности»**, разбитый на 4 этапа (12 работ):

**ЭТАП 1. Подготовка (3 работы):**
1. Разработка и утверждение устава проекта, проведение стартового совещания.
2. Анализ существующих регламентов информационной безопасности.
3. Проведение скрытой фишинг-атаки (замер «нулевого» уровня) и формирование отчёта об уязвимостях.

**ЭТАП 2. Настройка платформы (3 работы):**
4. Анализ рынка, выбор вендора и заключение договора с оплатой лицензии.
5. Создание учётных записей для 200 сотрудников.
6. Настройка интеграции с почтовым сервером (white-list IP-адресов).

**ЭТАП 3. Разработка контента и обучение (4 работы):**
7. Подготовка курса по Закону РБ № 99-З «О персональных данных».
8. Разработка интерактивных модулей по фишингу, социальной инженерии, видеолекции, база тестов.
9. Информирование сотрудников о старте программы.
10. Проведение активной фазы микрообучения (4 недели) и семинаров для отстающих.

**ЭТАП 4. Контроль и внедрение (2 работы):**
11. Проведение итоговой контрольной фишинг-атаки и финального тестирования.
12. Анализ достижения KPI, подготовка отчёта для директора и утверждение регламента регулярного обучения.

## Лист «ТАБЛИЦА ДАННЫХ» — расчётный движок (сетевой график)

Рабочая таблица для расчёта параметров сетевого графика по методу критического пути. Столбцы:

| Столбец | Формула / назначение |
|---|---|
| № | порядковый номер |
| ЗАДАЧА | название работы (раб1, раб2 …) |
| ПРЕДШЕСТВУЮЩИЕ РАБОТЫ | номера предшественников |
| ПОСЛЕДУЮЩИЕ РАБОТЫ | номера последователей |
| РАННИЙ СТАРТ (ES) | ES = МАКС(EF всех предшественников) |
| ДЛИТЕЛЬНОСТЬ (D) | сколько времени занимает задача |
| РАННИЙ ФИНИШ (EF) | EF = ES + D |
| ПОЗДНИЙ СТАРТ (LS) | LS = LF − D |
| ПОЗДНИЙ ФИНИШ (LF) | LF = МИН(LS всех последователей) |
| РЕЗЕРВ (TF) | TF = LS − ES — насколько можно задержать всю задачу |
| КРИТИЧЕСКИЙ ПУТЬ | «ДА», если резерв = 0, иначе «НЕТ» |

| Операция | Описание | Предшествующая операция | Время операции (дни) |

## Лист «Планировщик проекта» — интерактивная диаграмма Ганта

Основной рабочий лист-дашборд:
- **Выбор периода** (ползунок/поле «Рассматриваемый период», значения 1–60) — выделяет выбранный период на шкале справа.
- Таблица работ (№, действие, предшественники/последователи, резерв, раннее начало, длительность, признак критического пути) подтягивается по формулам с листа «ТАБЛИЦА ДАННЫХ».
- 60 столбцов-периодов (1–60) с условным форматированием, которое нужно закрашивает ячейки в зависимости от:
  - плановой длительности («Длительность (план.)»);
  - фактического начала («Начало (факт.)»);
  - % выполнения;
  - фактического (внепланового) выполнения и % выполнения (внепланово);
  - выбранного периода (подсветка текущего периода отдельным цветом);
  - чередующейся заливки чётных/нечётных периодов (для читаемости шкалы).

Это готовый шаблон диаграммы Ганта: достаточно заполнить лист «ТАБЛИЦА ДАННЫХ» своими задачами, длительностями и зависимостями — раннее начало, резерв и критический путь посчитаются автоматически, а на листе «Планировщик проекта» появится визуальная диаграмма Ганта с выделенным критическим путём.

### Как использовать этот инструмент для задания ПЗ-4
1. Перенести свою WBS (12–15 укрупнённых работ) в лист «ТАБЛИЦА ДАННЫХ», указав предшественников и длительность (в месяцах, как того требует задание).
2. Проверить автоматически рассчитанные раннее/позднее начало-окончание и резерв времени.
3. Перейти на лист «Планировщик проекта», выбрать нужный масштаб периода и убедиться, что диаграмма Ганта отражает все работы, их последовательность и критический путь (столбцы с резервом = 0).
4. При необходимости — оформить критический путь другим цветом отдельно, если условное форматирование не выделяет его автоматически по вашим данным.
