# Политика безопасности

## Область действия

Этот репозиторий содержит только учебные материалы (конспекты, презентации, документы,
файлы Excel с формулами) — исполняемого кода или веб-сервиса он не содержит. Тем не менее,
если в файлах Excel обнаружены макросы/VBA-скрипты, которые ведут себя не так, как описано
в документации, либо в опубликованных файлах случайно оказались персональные данные —
сообщите об этом, пожалуйста, как указано ниже.

## Как сообщить о проблеме

Не создавайте публичный issue для сообщения о:
- случайно опубликованных персональных данных;
- потенциально небезопасном содержимом (например, вредоносном макросе).

Вместо этого напишите автору репозитория напрямую через личные сообщения GitHub
(профиль [KsushaKhadzhinova](https://github.com/KsushaKhadzhinova)) с описанием проблемы
и файлом/строкой, где она обнаружена.

Для всех остальных замечаний (опечатки, фактические ошибки в конспектах) используйте
обычные [issues](../../issues) — см. [CONTRIBUTING.md](CONTRIBUTING.md).
