# Инструмент: Карта рисков в Excel (с форматированием)

*Источник: `Карта рисков в Excel_с форматированием -26 (3).xlsx`*

Готовый Excel-инструмент для регистрации, оценки и визуализации рисков проекта (автор шаблона указывает сайт `course-excel.ru`). Состоит из трёх листов.

## Лист «Таблица с рисками»

Реестр рисков проекта — таблица (Таблица1) со столбцами:

| Столбец | Назначение |
|---|---|
| Номер риска | Порядковый номер |
| Обозначение риска | Автоформула: `="R "&[Номер риска]&" "` |
| Наименование риска | Название риска |
| Влияние риска на проект/предприятие | Качественная оценка (например «средний») |
| Что является триггером для проявления данного риска? | Описание триггера |
| Оценка вероятности возникновения риска (от 0 до 1) | Числовая оценка |
| Оценка силы воздействия риска (от 0 до 1) | Числовая оценка |
| Итоговый коэффициент | Формула: `= Вероятность × Воздействие` |
| Мероприятия по минимизации рисков | Описание мер |

Условное форматирование ячеек коэффициента:
- `> 0.505` — высокий приоритет;
- `0.14–0.505` — средний приоритет;
- `< 0.14` — низкий приоритет.

### Шкалы для оценки (справочные таблицы на этом же листе)

**Шкала вероятности:**

| Оценка | Описание | Пример | % |
|---|---|---|---|
| 1 | Очень низкая | Единичный случай за 10 лет | < 5% |
| 2 | Низкая | Раз в 2–3 года | 5–20% |
| 3 | Средняя | Раз в год | 20–50% |
| 4 | Высокая | Несколько раз в год | 50–80% |
| 5 | Очень высокая | Регулярно / постоянно | > 80% |

**Шкала воздействия:**

| Оценка | Описание | Финансовые потери | Репутационный ущерб | Юридические последствия |
|---|---|---|---|---|
| 1 | Очень низкое | < 500 BYN | Локальный | Нет |
| 2 | Низкое | 500–3000 BYN | Внутренний | Штраф до 25 б.в. |
| 3 | Среднее | 3000–20000 BYN | Региональный | Штраф 25–50 б.в. |
| 4 | Высокое | 20000–100000 BYN | Национальный | Штраф 50–100 б.в., проверка НЦЗПД |
| 5 | Очень высокое | > 100 000 BYN | Международный | Блокировка деятельности, судебные иски |

## Лист «Карта рисков»

Визуализация реестра рисков в виде **пузырьковой/точечной диаграммы (карты риска)** по осям «Оценка вероятности возникновения риска» × «Оценка силы воздействия риска», с тремя зонами приоритета:
- **Высокий приоритет** — итоговый коэффициент от 0,505 до 1;
- **Средний приоритет** — от 0,14 до 0,505;
- **Низкий приоритет** — менее 0,14.

Лист содержит 3 варианта построения карты (с разными способами задания сетки/цветовых зон), а также подсказку, как подписать точки на графике значениями из ячеек:
1. Нажать правой кнопкой по точке на графике → «Добавить подписи данных».
2. Нажать правой кнопкой по подписи данных → «Формат подписей данных».
3. В параметрах подписи убрать галочки «Значения X» и «Линии выноски».
4. Выбрать галочку «Значение из ячеек» и сослаться на столбец с кратким наименованием рисков.

## Лист «Приветствие»
Вступительное сообщение автора шаблона (Татьяна, course-excel.ru) — обучающий файл для визуализации карты рисков.

---

### Как использовать этот инструмент для своего проекта
1. На листе «Таблица с рисками» указать название проекта, заполнить реестр (10–20 рисков), присвоить оценки вероятности и воздействия по шкалам.
2. Проверить автоматически рассчитанный «Итоговый коэффициент» и его цветовую индикацию приоритета.
3. Перейти на лист «Карта рисков» — убедиться, что риски корректно отобразились на карте; подписать точки названиями рисков.
4. Для каждого риска с высоким/критическим приоритетом — прописать мероприятия по минимизации.
