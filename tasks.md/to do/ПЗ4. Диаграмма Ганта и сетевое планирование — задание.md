# ПЗ-4. График Ганта: календарно-сетевое планирование

*Источник: `УП-ПЗ1-60121 (3).pptx`*

## Теоретическая часть (конспект для выполнения задания)

### Календарно-сетевое планирование
Процесс составления календарного плана работ в проекте: определение перечня работ, их логических взаимосвязей, исполнителей и продолжительности работ; ресурсные, временные и внешние ограничения и, на их основе, сроки выполнения. Результат — подробный план, который служит инструментом коммуникации, управления ожиданиями заинтересованных сторон и основой для подготовки отчётности об исполнении.

### Work Breakdown Structure (WBS)
Иерархическая декомпозиция проекта на более мелкие управляемые компоненты, задачи и работы; устанавливает иерархически структурированное распределение работ для всех задействованных работников. Декомпозиция — деление результатов проекта на меньшие компоненты до уровня пакетов работ. **Работы, не включённые в WBS, не являются работами проекта.**

**Основные ориентиры при создании структуры работ:**
- для каждого элемента структуры формулируется измеримый результат;
- результат вышестоящего элемента носит агрегированный характер (итог результатов «дочерних» элементов);
- пакеты и отдельные операции должны быть уникальными;
- структура должна быть полной, но не избыточной;
- элементы верхних уровней совместимы с организационной структурой проекта;
- размер элементов нижнего уровня достаточен для эффективного управления, но не избыточен для контроля.

**Подходы к созданию WBS:**
- а) продуктовый — по конечным модулям системы;
- б) по жизненному циклу — по этапам создания;
- в) функциональный — по специализациям команды;
- г) организационный — по территориальным/структурным единицам.


### Составление календарного плана проекта
- Работы связаны друг с другом зависимостями (Dependences), определяющими порядок их выполнения.
- Все работы объединяются в график работ (календарный план, Schedule).
- **Критические работы (Critical Tasks)** — работы, задержка которых отражается на сроках проекта.
- Критические работы образуют **критический путь (Critical Path)** — его продолжительность определяет продолжительность проекта.

**Типы зависимостей работ:**
- финиш – старт (FS)
- финиш – финиш (FF)
- старт – старт (SS)
- старт – финиш (SF)

**Виды операций:**
1. **Операция слияния** — имеет более одной непосредственно предшествующей операции.
2. **Параллельные операции** — могут выполняться одновременно по желанию РП (не зависят друг от друга).
3. **Дробящаяся операция** — за ней сразу следует несколько операций.

**Определение последовательности операций** — для каждой операции определяются: предшествующие операции; следующие операции; параллельные операции.

### Построение и анализ сетевых графиков
**Сетевой график** — графическое изображение технологической последовательности выполнения операций проекта с указанием их продолжительности и всех временных параметров.

Два подхода построения:
1. Операции в узлах (ОУ) / Метод предшествования (PDM) — используется чаще.
2. Операции на стрелках (ОС) / Метод стрелочных диаграмм (ADM).

**Диаграммы предшествования (Precedence Diagram)** — метод построения сетевой диаграммы, использующий прямоугольники (узлы) для операций, а зависимости отображаются стрелками.

### Пример упрощённой сети (проект нового бизнес-центра)

| Операция | Описание | Предшествующая операция |
|---|---|---|
| А | Утверждение приложения | Нет |
| В | Планы конструирования | А |
| С | Изучение трафика | А |
| D | Проверка наличия службы | А |
| Е | Отчёт персонала | В, С |
| F | Утверждение на комиссии | В, C, D |
| G | Ожидание работ | F |
| Н | Включение в работу | E, G |

С длительностями (рабочие дни):

| Операция | Описание | Предшествующая | Время (дни) |
|---|---|---|---|
| А | Утверждение приложения | нет | 5 |
| В | Планы конструирования | А | 15 |
| С | Изучение трафика | А | 10 |
| D | Проверка наличия службы | А | 5 |
| Е | Отчёт персонала | В, С | 15 |
| F | Одобрение комиссии | В, C, D | 10 |
| G | Ожидание работ | F | 170 |
| Н | Включение в работу | Е, G | 35 |

### Метод PERT
Оценка сроков начала и окончания работ — обозначения:
- **ID** — код операции; **Описание** — название операции; **Dur** — продолжительность;
- **ES** — ранний старт; **EF** — ранний финиш (EF = ES + Dur);
- **LS** — поздний старт (LS = LF − Dur); **LF** — поздний финиш;
- **TS (Total slack)** — резерв времени (для критического пути равен нулю);
- **i, j** — предыдущее/последующее событие.

Прямой анализ (ранние сроки): как скоро может начаться операция (ES)? как скоро закончиться (EF)? как скоро завершится проект в целом (ТЕ)?
Обратный анализ (поздние сроки): каковы самые поздние сроки завершения (LF) и начала (LS) операции? какие операции составляют критический путь? на какое время может быть задержана операция (резерв TS)?

### Диаграмма Ганта
Состоит из полос вдоль оси времени (горизонтальная ось). Каждая полоса представляет отдельную задачу: концы — моменты начала/завершения работы, протяжённость — длительность. Вертикальная ось — перечень задач.

## Задание к выполнению

1. **Построить иерархическую структуру работ (WBS).**
   Количество работ — 12–15 (укрупнённые этапы). Каждая работа должна иметь уникальный код в формате 1.0, 2.0, 3.0 и т. д. На верхнем уровне указывается название проекта, на втором — перечень основных этапов работ.

2. **Определить длительность каждой работы.**
   Для каждой работы из WBS установить плановую длительность в месяцах. Оценка длительности выполняется экспертным методом или по формуле PERT: **(O + 4M + P) / 6**. Длительности должны быть реалистичными и учитывать специфику IT-проекта.

3. **Определить взаимосвязи между работами.**
   Установить логические зависимости: какие работы должны быть завершены до начала других. Для каждой работы указать непосредственных предшественников. Взаимосвязи оформляются в виде таблицы с колонками: «Код работы», «Название работы», «Непосредственные предшественники».

4. **Построить диаграмму Ганта.**
   На основе полученных данных построить диаграмму Ганта, отображающую:
   - перечень работ по вертикали;
   - временную шкалу (месяцы) по горизонтали;
   - длительность каждой работы в виде горизонтальных полос;
   - последовательность и взаимосвязи работ;
   - критический путь (выделить цветом).
