# Инструкция: что и как делать (ПЗ4)

## 1. Что нужно подготовить лично тебе

- **Титульный лист** в `report.docx` — впиши ФИО/группу/дату.
- Если реальные длительности работ по твоему опыту/оценке руководителя отличаются от приведённых экспертных оценок — поправь словарь `tasks` в `calc_and_charts.py` (раздел 1) и перезапусти скрипт (см. ниже) — все диаграммы и таблицы пересчитаются автоматически.

## 3. Формулы, которые используются (и как их проверить руками)

**Прямой проход:**
- `ES(i) = max(EF(p))` по всем предшественникам `p` работы `i` (0, если предшественников нет)
- `EF(i) = ES(i) + D(i)`, где `D(i)` — длительность работы

**Обратный проход:**
- `LF(i) = min(LS(s))` по всем последователям `s` работы `i` (= длительности проекта, если последователей нет)
- `LS(i) = LF(i) − D(i)`

**Резерв времени (полный):**
- `Резерв(i) = LS(i) − ES(i)`. Если `Резерв = 0` → работа **критическая**.

**Метод PERT для отдельной работы (если нужна вероятностная оценка длительности):**
```
D = (O + 4·M + P) / 6
```
где `O` — оптимистическая, `M` — наиболее вероятная, `P` — пессимистическая оценка длительности.

Проверить расчёт для одной работы вручную можно по таблице `img/cpm_table.csv`, открыв её в Excel/LibreOffice.

## 4. Как перестроить диаграммы

```bash
cd pz4
python calc_and_charts.py
```
После изменения длительностей/предшественников в разделе 1 скрипта запусти его заново — файлы `img/*.png` и `img/cpm_table.csv` перезапишутся.

## 5. Как использовать `gantt-planner.xlsx` + `modGanttCriticalPath.bas`

1. Открой `gantt-planner.xlsx`.
2. Alt+F11 → Insert → Module → вставь содержимое `modGanttCriticalPath.bas`.
3. Alt+F8 → `RunAll` → «Выполнить». Макрос заполнит лист «ТАБЛИЦА ДАННЫХ» (15 работ), рассчитает ES/EF/LS/LF/резерв и покрасит строки критического пути на листе «Планировщик проекта» красным.
4. Проверь, что расчётная длительность проекта (в диалоговом окне макроса) совпадает с `report.md` — **7 месяцев**.
5. Сохрани файл.

## 6. Какие скриншоты приложить к финальной сдаче

1. Скриншот заполненного листа «ТАБЛИЦА ДАННЫХ» в Excel после запуска макроса.
2. Скриншот листа «Планировщик проекта» с подсвеченным критическим путём.
3. Диаграмма Ганта `img/gantt_critical_path.png` (уже вставлена в отчёт).
4. Сетевой график `img/network_diagram.png` (уже вставлен в отчёт).
