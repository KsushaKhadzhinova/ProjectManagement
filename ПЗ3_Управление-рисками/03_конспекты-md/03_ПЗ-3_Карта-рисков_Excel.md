### Лист «Карта рисков»
Заголовок: `="Карта рисков для проекта "&'Таблица с рисками'!C1`. Три варианта карты:

1. **Вариант 1 — точечная диаграмма.** X — вероятность, Y — воздействие, точки подписаны R1…Rn. Подписи ставятся так:
   1. ПКМ по точке → «Добавить подписи данных»;
   2. ПКМ по подписям → «Формат подписей данных»;
   3. снять «Значения X» и «Линии выноски»;
   4. отметить «Значения из ячеек» → диапазон с обозначениями рисков.
2. **Вариант 2 — зоны.** Воздействие (0,1–0,5 / 0,5–0,6 / 0,6–0,8 / 0,8–1) × вероятность (0,1–0,4 / 0,4–0,6 / 0,6–0,8 / 0,8–1). Цвета: высокий, средний, низкий приоритет.
3. **Вариант 3 — тепловая матрица 10×10.** Ячейка = вероятность × воздействие (`=$B49*C$59`). Пороги итогового коэффициента:
   - 🔴 **высокий** — от 0,505 до 1;
   - 🟡 **средний** — от 0,14 до 0,505;
   - 🟢 **низкий** — менее 0,14.

## Порядок выполнения
1. Вписать название проекта в «Таблица с рисками».
2. Выявить 10–15 рисков: мозговой штурм, чек-листы Боэма и ДеМарко–Листера, SWOT. Включить технические, организационные, правовые (Закон № 99-З) и финансовые риски, а также 1–2 возможности.
3. Для каждого риска заполнить последствия, триггер, вероятность и воздействие (0–1, опираясь на шкалы 1–5 → 0,2…1,0).
4. Проверить, что H = F × G посчитался; выставить приоритет по порогам 0,14 и 0,505.
5. Для каждого риска выбрать стратегию (уклонение, снижение, передача, принятие) и конкретные меры.
6. Построить карту (вариант 1 обязательно, варианты 2–3 — для наглядности) и подписать точки.
7. В отчёт: реестр, шкалы, карта, топ-3 риска с планом реагирования, вывод.
