# Инструкция: что и как делать (ПЗ1)

## 1. Что нужно подготовить лично тебе (не сгенерировано автоматически)

- **Титульный лист** — впиши свою фамилию/группу/дату защиты в `report.docx` (поля `<ФИО>`, `<группа>`, `<дата>` — ищи в начале файла).
- **Скриншот реестра стейкхолдеров** — открой `docs/business/02-stakeholders.md` проекта NotaCode на GitHub (отрендеренную таблицу §1) и сделай скриншот всей таблицы SH-01…SH-17 (может понадобиться 2 скрина, если таблица не помещается).
- **Скриншот доски GitHub Projects** (если используешь) — для иллюстрации MoSCoW/эпиков, необязательно, но повышает наглядность.
- **Данные для реальных дат** — уточни у руководителя фактическую дату защиты курсовой и подставь вместо допущения A-02, если она уже известна.

## 3. Формулы и расчёты, которые нужно проверить

- **Правило MoSCoW «Must ≤ 60 %»** — посчитай долю пунктов Must от общего числа пунктов во всех 4 категориях (Must+Should+Could+Won't) в разделе 2.1 `report.md`. Если получится больше 60 % — перенеси 1–2 пункта в Should с пометкой в тексте.
- **Шкала влияние/интерес стейкхолдеров** — используется шкала 1–5 (не 0–1); при желании изменить конкретные значения для своих стейкхолдеров — поправь массив `stakeholders` в `../pz4/calc_and_charts.py` (раздел 4) и перезапусти скрипт (см. ниже), диаграмма перестроится.

## 4. Как перестроить диаграммы (если меняешь данные)

```bash
python ../pz4/calc_and_charts.py
```

Скрипт пересчитает и перезапишет `img/stakeholder_quadrant.png` и `img/risk_map.png` (общий скрипт для ПЗ1 и ПЗ4, лежит в `pz4/`, т.к. также считает критический путь для ПЗ4).

## 5. Как использовать `../risk-map/risk-map.xlsx` + `../risk-map/modRiskMap.bas`

1. Открой `../risk-map/risk-map.xlsx` в Excel.
2. Alt+F11 → Insert → Module → вставь содержимое `../risk-map/modRiskMap.bas`.
3. Alt+F8 → выбери `RunAll` → «Выполнить». Макрос заполнит реестр рисков (15 строк) и подпишет точки на карте рисков именами рисков.
4. Сохрани файл.

## 6. Какие скриншоты приложить к финальной сдаче (для препода)

1. Скриншот заполненной таблицы 5W (раздел 1.1 `report.docx`).
2. Скриншот таблицы MoSCoW с подсчитанной долей Must.
3. Скриншот дерева декомпозиции задач (раздел 4).
4. Скриншот `img/stakeholder_quadrant.png` (уже вставлен в отчёт).
5. Скриншот работы макроса `../risk-map/modRiskMap.bas` в Excel (до/после запуска).
