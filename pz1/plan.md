# План выполнения ПЗ1 «Разработка концепции проекта»

Практическое задание выполняется на реальном проекте **[NotaCode](https://github.com/KsushaKhadzhinova/NotaCode)** — веб-IDE «diagram as code» для формальных нотаций моделирования.

## Откуда берутся данные

В проекте NotaCode уже существуют черновики бизнес-документации (`docs/business/`), которые используются как первичный источник для заполнения формы ПЗ1:

| Раздел ПЗ1 | Источник в NotaCode |
|---|---|
| 5W, проблемы/решения | `docs/business/01-project-concept.md` |
| SMART-цель | `docs/business/03-smart-goals.md` (раздел 1, цель PG-01) |
| MoSCoW | `docs/planning/agile-plan.md` §8 |
| Стейкхолдеры | `docs/business/02-stakeholders.md` |
| Декомпозиция задач | `docs/planning/agile-plan.md` §7 (эпики E0–E13) |

## Порядок работы

1. **(15 мин)** Зафиксировать рабочие допущения о датах: старт S0 — 21.09.2026, MVP — 06.12.2026, защита — 18.12.2026 (допущение A-02 из `03-smart-goals.md`).
2. **(30 мин)** Раздел 1 (Business Case): перенести таблицу проблем P-01…P-06 и 5W-таблицу из `01-project-concept.md`; сформулировать одну итоговую SMART-фразу; описать допущения и правила приёмки.
3. **(20 мин)** Раздел 2 (Scope): перенести MoSCoW из `agile-plan.md §8`, проверить правило «Must ≤ 60 %»; выписать исключения (категория Won't).
4. **(15 мин)** Раздел 3 (Ограничения): заполнить таблицу по 6 категориям на основе стека и организационных условий проекта.
5. **(30 мин)** Раздел 4 (Декомпозиция): развернуть 13 эпизодов E0–E13 в дерево из 15–25 задач.
6. **(15 мин)** Раздел 5 (Стейкхолдеры): взять реестр SH-01…SH-17 из `02-stakeholders.md`, построить матрицу квадрантов (см. `img/stakeholder_quadrant.png`, сгенерирован скриптом `pz4/calc_and_charts.py`).
7. **(10 мин)** Раздел 6 (Выводы) и финальная сверка стиля документа.

Итоговый документ — [report.md](report.md) (и его STP-форматированная версия [report.docx](report.docx)).
