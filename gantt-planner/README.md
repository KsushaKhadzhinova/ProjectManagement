# Инструмент: Планировщик проекта на основе диаграммы Ганта

Заполненная копия оригинального шаблона `to do/Планировщик проекта на основе диаграммы Ганта - 60121 (3).xlsx` с расчётом критического пути (CPM) для WBS проекта NotaCode и VBA-макросом автозаполнения.

- **`gantt-planner.xlsx`** — рабочая копия инструмента.
- **`modGanttCriticalPath.bas`** — VBA-макрос: заполняет лист «ТАБЛИЦА ДАННЫХ» 15 работами WBS, считает ES/EF/LS/LF/резерв методом критического пути и подсвечивает критический путь на листе «Планировщик проекта».

## Как использовать

1. Открой `gantt-planner.xlsx`.
2. Alt+F11 → Insert → Module → вставь `modGanttCriticalPath.bas`.
3. Alt+F8 → `RunAll` → «Выполнить». Ожидаемый результат в диалоговом окне: длительность проекта **7 месяцев**.

Подробное описание содержимого инструмента — см. [`to do/Инструмент — Планировщик проекта (диаграмма Ганта).md`](../to%20do/Инструмент%20—%20Планировщик%20проекта%20(диаграмма%20Ганта).md).

Этот инструмент используется как вспомогательный материал к заданию **ПЗ4** (см. [`../pz4/`](../pz4/)) — тот же расчёт критического пути продублирован там на Python (`pz4/calc_and_charts.py`) для сверки результатов.
