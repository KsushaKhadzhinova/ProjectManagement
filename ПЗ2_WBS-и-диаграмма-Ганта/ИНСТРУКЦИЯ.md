- «Рисунок 2.1 – …» по центру, «Таблица 2.1 – …» слева над таблицей, «Продолжение таблицы 2.1» на переносе;
- формулы с номерами (2.1) справа;

## 2. Способы выполнения

### Способ А — VBA-макрос в Excel (рекомендуется для защиты: видно, что расчёт сделан в Excel)
1. Откройте `02_задание-оригиналы/Планировщик проекта на основе диаграммы Ганта - 60121.xlsx`.
2. **Файл → Сохранить как → «Книга Excel с поддержкой макросов (*.xlsm)»**.
3. `Alt + F11` → **File → Import File…** → `05_vba/ПЗ2_NotaCode_CPM_Gantt.bas`.
   Файл в кодировке Windows-1251, русские буквы отобразятся нормально. Читаемая копия для GitHub — `*.bas.utf8.txt`.
4. Закройте редактор, нажмите `Alt + F8` → `PZ2_RunAll` → **Выполнить**.
5. Если макросы заблокированы: **Файл → Сведения → Включить содержимое**. Для файла из интернета: ПКМ по файлу → Свойства → «Разблокировать».
6. Результат:
   - лист **«WBS NotaCode»** — 14 работ, O/M/P, формулы `=(O+4M+P)/6`, `=(P-O)/6`, недели;
   - **«ТАБЛИЦА ДАННЫХ»** — задачи, предшественники, последователи, ES, D, EF, LS, LF, резерв, «ДА/НЕТ»;
   - **«Планировщик проекта»** — Гант шаблона, период J2 = 12;
   - **«Гант NotaCode»** — собственный Гант с датами, критические работы — красные, резервы — штриховка;
   - окно с итогом: 11 нед. = 2,75 мес., КП 1.0 → 2.0 → 4.0 → 5.0 → 10.0 → 11.0 → 13.0 → 14.0.

### Способ В — вручную
Заполните «ТАБЛИЦА ДАННЫХ» по таблице из `ОТЧЁТ.md`, раздел 5 (в неделях, ES первой работы = 1). Формулы:

| Столбец | Формула (строка 8) | Смысл |
|---|---|---|
| F (ES) | `1` или `=H<предш.>` или `=MAX(H<п1>;H<п2>)` | ранний старт |
| G (D) | число недель | длительность |
| H (EF) | `=F8+G8` | ранний финиш |
| J (LF) | `=I<послед.>` или `=MIN(I<с1>;I<с2>)`; для последней — `=MAX($H$8:$H$21)` | поздний финиш |
| I (LS) | `=J8-G8` | поздний старт |
| K (TS) | `=I8-F8` | резерв |
| L | `=ЕСЛИ(K8=0;"ДА";"НЕТ ")` | критический путь |

⚠️ Предшественников с несколькими номерами вводите как текст (`'3, 4`), иначе Excel превратит «3.4» в дробь.

## 5. Расчёты и формулы (для защиты)
- **PERT:** T = (O + 4M + P) / 6; σ = (P − O) / 6. Пример для 5.0: (0,5 + 4·0,75 + 1) / 6 = 0,75 мес.
- **CPM:** ES = max(EF пред.), EF = ES + D, LF = min(LS посл.), LS = LF − D, TS = LS − ES.
- **Длительность проекта** = EF последней работы = 2,75 мес. = сумма D работ критического пути.
- **σ проекта** = √(Σσ² по КП) = 0,143 мес. → с 95 % вероятностью не более 3,04 мес.
- **Перевод единиц:** 1 мес. = 4 нед.; дата = 21.09.2026 + ES × 4 недели.

## 6. Частые вопросы на защите
- *Почему 5.0 критическая?* Самая длинная работа сервера, от неё зависят и 6.0, и 10.0.
- *Что будет при задержке 12.0 на 2 недели?* Ничего: резерв 3 недели.
- *Почему недели в Excel, а в задании месяцы?* Периоды планировщика целые; 1 период = 0,25 мес.
