## Задание (слайд 28)
1. **Построить WBS.** 12–15 работ (укрупнённые этапы), у каждой уникальный код 1.0, 2.0, 3.0… Верхний уровень — название проекта, второй — перечень основных этапов.
2. **Определить длительность каждой работы** — плановая длительность **в месяцах**, экспертным методом или по формуле PERT **(O + 4M + P) / 6**. Длительности реалистичные, с учётом специфики ИТ-проекта.
3. **Определить взаимосвязи:** какие работы должны завершиться до начала других; для каждой работы указать непосредственных предшественников. Таблица: «Код работы», «Название работы», «Непосредственные предшественники».
4. **Построить диаграмму Ганта:**
   - перечень работ по вертикали;
   - временная шкала (месяцы) по горизонтали;
   - длительность каждой работы — горизонтальные полосы;
   - последовательность и взаимосвязи работ;
   - **критический путь выделен цветом.**

### Лист «Пример 1» — проект «Обучение сотрудников кибербезопасности» (пометка «ИИ»: пример сгенерирован ИИ)
**WBS (4 этапа, 12 работ):**
- **Этап 1. Подготовка:**
  1. устав проекта и стартовое совещание;
  2. анализ регламентов ИБ;
  3. скрытая фишинг-атака (замер «нулевого» уровня) и отчёт об уязвимостях.
- **Этап 2. Настройка платформы:**
  4. анализ рынка, выбор вендора, договор с оплатой лицензии;
  5. учётные записи для 200 сотрудников;
  6. интеграция с почтовым сервером (white-list IP).
- **Этап 3. Контент и обучение:**
  7. курс по Закону РБ № 99-З «О защите персональных данных»;
  8. интерактивные модули по фишингу и социальной инженерии, видеолекции, тесты;
  9. информирование сотрудников;
  10. микрообучение (4 недели) и семинары для отстающих.
- **Этап 4. Контроль и внедрение:**
  11. итоговая фишинг-атака и тестирование;
  12. анализ KPI, отчёт директору, регламент регулярного обучения.

### Лист «ТАБЛИЦА ДАННЫХ» — расчётная таблица CPM (заполняется студентом)
Столбцы: № · Задача · Предшествующие работы · Последующие работы · **Ранний старт** · **Длительность** · **Ранний финиш** · **Поздний старт** · **Поздний финиш** · **Резерв** · **Критический путь**.

| Столбец | Формула / правило (из подсказок в файле) |
|---|---|
| ES | = МАКС(EF всех предшественников); первая работа начинается с 1 |
| D | длительность задачи |
| EF | `=ES + D` |
| LF | = МИН(LS всех последователей); для последней работы LF = EF |
| LS | `=LF − D` |
| Резерв (TF) | `=LS − ES` — насколько можно задержать задачу |
| Критический путь | `=IF(Резерв=0;"ДА";"НЕТ")` |

Демонстрационные данные: раб1…раб7. Критический путь — раб1 (1–3) → раб3 (3–7) → раб6 (7–13). Резервы: раб2 — 5, раб4 — 7, раб5 — 4, раб7 — 4.
⚠️ Номера нескольких предшественников записаны через точку («2.3», «4.5», «3.4») — это список «2 и 3», а не дробь. Excel показывает их как 2.2999… Вводите такие ячейки как текст.
В этой же таблице лежит учебный пример «Бизнес-центр» (A–H, 235 дней; разбор — в теоретическом файле).

### Лист «Планировщик проекта» — диаграмма Ганта
- Шапка: «Выберите период для выделения», поле «Рассматриваемый период» (по умолчанию 60). Легенда: длительность (план.), начало (факт.), % выполнения, фактически (внепланово), % выполнения (внепланово).
- Столбцы: № · Действие · Предшествующие · Последующие · Резерв · Раннее начало · Длительность · Критический путь · **Периоды 1…60**.
- Все значения подтягиваются формулами из «ТАБЛИЦА ДАННЫХ» (`='ТАБЛИЦА ДАННЫХ'!C8` и т. д.). Критический путь = `IF(L="да";100%;0)`: условное форматирование окрашивает полосы критических работ.
- 25 строк работ; пустые строки отображают 0.

## Порядок выполнения
1. Составить WBS на 12–15 работ с кодами 1.0…N.0.
2. Оценить длительности в месяцах (PERT: записать O, M, P и результат).
3. Заполнить таблицу «Код — Название — Предшественники».
4. Внести работы в «ТАБЛИЦА ДАННЫХ»: задача, предшественники, последователи, ES, D; LF — обратным проходом.
5. Проверить, что резерв = 0 ровно у критических работ и что длина критического пути равна EF последней работы.
6. Открыть «Планировщик проекта», задать «Рассматриваемый период» ≥ длительности проекта и убедиться, что критические полосы выделены цветом.
7. Оформить отчёт: WBS-дерево, таблица зависимостей, сетевой график (PDM), таблица расчёта, скриншот диаграммы Ганта, вывод (длительность проекта, критический путь, резервы).
