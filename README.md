# Управление проектами — практические задания

Репозиторий с материалами и выполненными практическими заданиями по дисциплине **«Управление проектами»** (БГУИР, кафедра микропроцессорных систем и сетей). Все практические задания выполнены на примере реального учебного IT-проекта **[NotaCode](https://github.com/KsushaKhadzhinova/NotaCode)** — веб-IDE «diagram as code» для формальных нотаций моделирования (UML, BPMN, ERD, IDEF0/1X/3, DFD, сети Петри).

## Зачем этот репозиторий

Курс даёт 11 исходных материалов: 7 теоретических (презентации/документы по темам курса) и 4 практических (2 задания на оценку + 2 Excel-инструмента). Здесь:
- теория переведена в читаемые markdown-конспекты рядом с оригиналами;
- оба практических задания **выполнены целиком** — не шаблоны с пустыми полями, а заполненные отчёты с реальными данными, расчётами и диаграммами;
- оба Excel-инструмента заполнены и снабжены VBA-макросами, автоматизирующими расчёты;
- все вычисления (метод критического пути, диаграммы) продублированы и на Python — для проверки и повторяемости.

## Структура репозитория

```
theory/            — конспекты по 6 темам курса (.md) + оригиналы презентаций/документов
to do/              — шаблоны заданий и условия Excel-инструментов в исходном (пустом) виде
pz1/                — ВЫПОЛНЕННОЕ задание ПЗ1 «Разработка концепции проекта»
pz4/                — ВЫПОЛНЕННОЕ задание ПЗ4 «Диаграмма Ганта и сетевое планирование»
risk-map/           — заполненный инструмент «Карта рисков в Excel» + VBA
gantt-planner/      — заполненный инструмент «Планировщик проекта на основе диаграммы Ганта» + VBA
ARCHITECTURE.md     — подробный разбор структуры репозитория, файл за файлом
CHECKLIST-1-ALL-TASKS.md          — сводный чек-лист проверки всех 4 практических позиций
CHECKLIST-2-SOURCE-REQUIREMENTS.md — чек-лист «что именно требовал каждый из 11 исходных файлов»
```

Подробнее про назначение каждого файла — см. [ARCHITECTURE.md](ARCHITECTURE.md).

## Что лежит в `pz1/` — ПЗ1 «Разработка концепции проекта»

Полностью заполненный отчёт по шаблону `to do/шаблон пз1 -УП- 26 (4).docx`, на данных реального проекта NotaCode: модель 5W, таблица «Проблемы → Решения», SMART-цель (по критериям и одной итоговой фразой), MoSCoW-приоритизация (с проверкой правила «Must ≤ 60 %», фактически 44 %), 6 категорий ограничений, декомпозиция цели на 25 задач деревом, реестр из 17 стейкхолдеров с матрицей влияние/интерес и распределением по 4 квадрантам.

Файлы: `plan.md` (план выполнения) · `instructions.md` (что сделать самому, какие скриншоты/формулы нужны) · `report.md`/`report.docx` (сам отчёт, `.docx` оформлен по СТП 01–2024 БГУИР) · `checklist.md` · `summary.md` · `img/stakeholder_quadrant.png`.

## Что лежит в `pz4/` — ПЗ4 «Диаграмма Ганта и сетевое планирование»

Классическая сетевая модель по методу критического пути (CPM) для WBS из 15 укрупнённых работ проекта NotaCode: длительности в месяцах (с примером расчёта по формуле PERT), таблица предшественников, полный расчёт ES/EF/LS/LF/резерв для каждой работы, найденный критический путь (10 из 15 работ, итоговая длительность проекта — 7 месяцев), диаграмма Ганта и сетевой график.

Файлы: `plan.md` · `instructions.md` · `report.md`/`report.docx` · `checklist.md` · `summary.md` · `calc_and_charts.py` (Python-расчёт CPM и построение всех диаграмм) · `img/gantt_critical_path.png`, `img/network_diagram.png`, `img/cpm_table.csv`.

## Что лежит в `risk-map/` и `gantt-planner/`

Заполненные копии двух Excel-инструментов курса с VBA-макросами, которые сами выполняют расчёт (не нужно вручную протягивать формулы):

- **`risk-map/`** — реестр из 15 реальных рисков проекта NotaCode (не абстрактных примеров) со шкалой вероятность×воздействие, автоматической приоритизацией и картой рисков; макрос `modRiskMap.bas` заполняет реестр и подписывает точки на графике.
- **`gantt-planner/`** — тот же расчёт критического пути, что и в `pz4/`, но выполненный средствами Excel; макрос `modGanttCriticalPath.bas` заполняет таблицу данных, считает CPM и подсвечивает критический путь на листе диаграммы.

## Как пользоваться репозиторием

1. Начни с [ARCHITECTURE.md](ARCHITECTURE.md) — там ровно один раз объяснено, что где лежит и как всё связано.
2. Для сдачи задания — открой `report.docx` в соответствующей папке (`pz1/` или `pz4/`), впиши свои ФИО/группу на титульном листе и следуй `checklist.md`.
3. Для проверки Excel-инструментов и запуска макросов — см. `README.md` внутри `risk-map/` и `gantt-planner/`.
4. Если нужно пересчитать данные под свои условия (другие длительности, другие риски, другие стейкхолдеры) — правь `pz4/calc_and_charts.py` и перезапускай его; все диаграммы и CSV перестроятся автоматически.
5. Перед финальной сдачей пройди [CHECKLIST-1-ALL-TASKS.md](CHECKLIST-1-ALL-TASKS.md) — сводный чек-лист по всем 4 позициям — и [CHECKLIST-2-SOURCE-REQUIREMENTS.md](CHECKLIST-2-SOURCE-REQUIREMENTS.md) — сверку с исходными требованиями курса.
