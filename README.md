# Управление проектами — практические задания

Репозиторий с материалами и выполненными практическими заданиями по дисциплине **«Управление проектами»** (БГУИР).

## Структура репозитория

```
theory/     — конспекты по темам курса (Markdown) + оригинальные материалы (pptx/ppt/docx)
to do/      — выполненные практические задания (Markdown) + оригинальные шаблоны/инструменты (docx/pptx/xlsx)
```

| Раздел | Содержимое |
|---|---|
| [`theory/`](theory) | Тема 1 (введение в УП), Тема 2 (ЖЦ разработки ПО), Тема 3 (методологии разработки), управление рисками, SMART-цели, стейкхолдеры проекта — конспекты + оригинальные презентации/документы |
| [`to do/`](to%20do) | ПЗ1 (концепция проекта), ПЗ4 (WBS и диаграмма Ганта), инструмент «Карта рисков» (Excel), инструмент «Планировщик проекта» (Excel, диаграмма Ганта) |

## Как пользоваться

1. Открой конспект нужной темы в `theory/` — там разобрана теория с примерами.
2. В `to do/` — шаблоны заданий и готовые Excel-инструменты с формулами (риск-карта, критический путь и диаграмма Ганта).
3. Оригинальные файлы (`.pptx`, `.ppt`, `.docx`, `.xlsx`) сохранены рядом с конспектами для сверки.
