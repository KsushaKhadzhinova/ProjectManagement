# Управление проектами

Материалы и практические задания по дисциплине «Управление проектами» (БГУИР).

Задания (ПЗ1, ПЗ4) и оба Excel-инструмента выполнены на примере моего проекта NotaCode (веб-IDE для диаграмм на собственном DSL: UML, BPMN, ERD, IDEF0/1X/3, DFD, сети Петри).

## Структура

- `theory/` — конспекты по темам курса + оригинальные презентации/документы
- `to do/` — исходные шаблоны заданий и условия Excel-инструментов
- `pz1/` — выполненное ПЗ1 «Разработка концепции проекта»
- `pz4/` — выполненное ПЗ4 «Диаграмма Ганта и сетевое планирование»
- `risk-map/` — заполненная карта рисков (Excel + макрос)
- `gantt-planner/` — заполненный планировщик Ганта (Excel + макрос)
- `ARCHITECTURE.md` — что где лежит, подробнее
- `CHECKLIST-1-ALL-TASKS.md`, `CHECKLIST-2-SOURCE-REQUIREMENTS.md` — чек-листы для проверки перед сдачей

## Что внутри ПЗ1

5W, таблица проблем/решений, SMART-цель, MoSCoW (Must ≤ 60%), 6 категорий ограничений, декомпозиция на 25 задач, реестр стейкхолдеров с матрицей влияние/интерес.

Файлы: `plan.md`, `instructions.md`, `report.md`/`report.docx` (оформлен по СТП БГУИР), `checklist.md`, `summary.md`.

## Что внутри ПЗ4

WBS из 15 работ, расчёт критического пути (CPM) — длительность проекта 7 месяцев, критический путь из 10 работ, диаграмма Ганта и сетевой график. Расчёт продублирован в Excel (`gantt-planner/`) и на Python (`pz4/calc_and_charts.py`).

Файлы: `plan.md`, `instructions.md`, `report.md`/`report.docx`, `checklist.md`, `summary.md`.

## Перед сдачей

1. Вписать ФИО и группу на титульном листе `report.docx`.
2. Пройти `checklist.md` в папке задания.
3. Пройти `CHECKLIST-1-ALL-TASKS.md` и `CHECKLIST-2-SOURCE-REQUIREMENTS.md`.

## Ветки

`feature/pz1`, `feature/pz4`, `feature/risk-map`, `feature/gantt-planner` — по одной на каждую позицию, всё объединено в `master`.
