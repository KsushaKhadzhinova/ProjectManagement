# Операции, требующие ручного выполнения

Перечень операций, выполнение которых требует учётной записи исполнителя (Google, LMS) или Microsoft Word/Excel.

## 1. Снимок карты рисков

1. Открыть Google Таблицу (ссылка в `README.md`), лист «Риски».
2. Снять область точечной диаграммы «Карта рисков DiagramCode» (Win + Shift + S).
3. Сохранить как `risk-management/Карта рисков - скриншот.png`.
4. В `risk-management/Отчёт - ПЗ3 - Управление рисками проекта.docx` (раздел 2.4) заменить курсивную заглушку «[Сюда вставить скриншот карты рисков…]» рисунком. Подпись рисунка присутствует в документе.

Перестроение листов таблицы: «Расширения → Apps Script → Run».

## 2. Проверка отчётов в Word

Файлы:
- `pz1-concept/ПЗ1 - Концепция проекта - DiagramCode - Хаджинова.docx`
- `pz1-concept/Отчёт - ПЗ1 - Концепция проекта.docx`
- `pz-wbs-gantt/Отчёт - ПЗ2 - WBS и график Ганта.docx`
- `risk-management/Отчёт - ПЗ3 - Управление рисками проекта.docx`

Операции:
- обновление оглавления: контекстное меню поля → «Обновить поле» → «Обновить целиком» (в шаблоне ПЗ1 оглавление отсутствует);
- контроль расположения таблиц и рисунков, ФИО и группы на титульном листе;
- ПЗ1, раздел 1.3, строка «T (К какому сроку сделаем?)»: значение «по расписанию сессии группы 60121» заменяется датой защиты после её назначения.

## 3. Выбор сдаваемого варианта ПЗ2

Формулировке задания соответствует вариант Б («Пример 1»). Вариант А (DiagramCode) сдаётся дополнительно по согласованию с преподавателем.

## 5. Проверка в Microsoft Excel

1. Открыть `.xlsx`, снять режим защищённого просмотра («Разрешить редактирование»).
2. Выполнить полный пересчёт: Ctrl + Alt + F9.
3. Сверить значения с эталонными таблицами документа `EXCEL-ФАЙЛЫ - СТРУКТУРА И ФОРМУЛЫ.md`.

Экспорт из Google Таблиц: «Файл → Скачать → Microsoft Excel (.xlsx)». Функции `TEXTJOIN` и `FILTER` (строка «Критический путь») поддерживаются в Excel 2021 и Microsoft 365; в более ранних версиях ячейка возвращает `#ИМЯ?`, остальные расчёты не затрагиваются.

## 6. Доступ скрипта Apps Script

Отзыв доступа: `myaccount.google.com/permissions` → «Untitled project» → «Удалить доступ». После отзыва перестроение листов недоступно.
